## 🎯 Using the tool

You do not need to change how you work. The tool monitors the messages sent by your coding agent. When the agent starts a long explanation, the tool identifies the actual code or answer. It highlights this information in a clear box at the top of the chat window. 

This ensures you see the solution without scanning through paragraphs of text. If you want the full context, scroll down to see the rest of the agent's message. 

## ❓ Troubleshooting common issues

If the software does not work, verify these points:

* **The tool does not appear:** Restart your coding agent. Ensure the tool is running in your taskbar.
* **The agent still writes long messages:** Check the settings menu to ensure the plugin state says "Active." You might need to refresh your coding window.
* **Screen flickering:** This happens sometimes due to the way the text is reformatted. Turn off "Overlay Mode" in the settings if this becomes a bother.

## 🛡️ Privacy and safety

This tool runs locally on your machine. It reads text within your coding agent window to process the layout. It does not send your code to external servers. Your projects remain private. No sensitive data leaves your computer during this process.

## 📋 Customizing settings

You can change how the tool presents information:

* **Compact Mode:** This merges the highlighted answer into the chat flow more tightly.
* **Alert Sound:** You can enable a subtle sound that plays when the agent provides a new answer in a simplified format.
* **Font Scaling:** Adjust the text size of the tool’s output boxes to match your screen preferences.
